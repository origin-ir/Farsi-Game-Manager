# 🎮 Farsi Game Manager
## مدیریت حرفه‌ای فارسی‌سازی‌های بازی

برنامه‌ای مدرن و حرفه‌ای برای دانلود و مدیریت فایل‌های فارسی‌سازی بازی‌ها

---

## ✨ ویژگی‌های اصلی

### 🎨 رابط کاربری زیبا و مدرن
- **Theme تاریک** برای حفاظت از چشم در محیط کم‌نور
- **Smooth Animations & Transitions** برای تجربه کاربری عالی
- **Responsive Design** که روی تمام اندازه‌های صفحه کار می‌کند
- **رابط فارسی** کامل و بومی

### 📦 قابلیت‌های دانلود
- **GitHub Integration**: اتصال مستقیم به مخزن Farsi-Origin
- **دانلود خودکار**: دریافت سریع فایل‌های فارسی‌سازی
- **Progress Tracking**: نمایش وضعیت دانلود با درصد
- **دانلود موازی**: دانلود چندین محصول به طور همزمان (نسخه آینده)

### 📁 مدیریت فایل‌ها
- **خودکار دانلود**: فایل‌ها به `Downloads/Farsi-Game-Manager` ذخیره می‌شوند
- **Caching System**: ذخیره محصولات برای دسترسی آفلاین
- **فایل زیپ**: هر محصول شامل تمام فایل‌های لازم
- **سهل‌ترین دسترسی**: دکمه باز کردن پوشه برای رفتن سریع به فایل‌ها

### 🔧 قابلیت‌های فنی
- **بدون باگ**: کد تست شده و بهینه
- **عملکرد سریع**: استفاده از Threading برای UI بدون انجماد
- **Memory Efficient**: استفاده بهینه از منابع سیستم
- **Error Handling**: مدیریت خطاها و اتصالات ناپایدار

## 🚀 نحوه نصب و اجرا

### روش 1: استفاده از EXE (آسان‌ترین)

1. فایل `Farsi-Game-Manager.exe` را دانلود کنید
2. دو بار روی آن کلیک کنید
3. برنامه شروع می‌شود! 🎉

**نیاز به نصب Python ندارد!**

### روش 2: از کد منبع (برای توسعه‌دهندگان)

#### پیش‌نیازها:
- Python 3.8+
- pip (Package Manager)

#### مراحل:

```bash
# 1. Repository را Clone کنید
git clone https://github.com/Origin-Core/Farsi-Game-Manager.git
cd Farsi-Game-Manager

# 2. Dependencies را نصب کنید
pip install -r requirements.txt

# 3. برنامه را اجرا کنید
python main.py
```

### روش 3: ساختن EXE شخصی (برای Windows)

```bash
# Windows Command Prompt میں
python build_exe_for_windows.py

# یا
build.bat
```

## 📋 نحوه استفاده

### 1️⃣ اجرای برنامه
- برنامه را باز کنید
- لیست محصولات به طور خودکار بارگذاری می‌شوند

### 2️⃣ انتخاب محصول
- روی کارت محصول مورد نظر کلیک کنید
- اطلاعات محصول را مشاهده کنید

### 3️⃣ دانلود فایل
- دکمه "📥 دانلود زیرنویس" را کلیک کنید
- پیشرفت دانلود را مشاهده کنید
- بعد از تکمیل، بر روی "🗂️ باز کردن پوشه" کلیک کنید

### 4️⃣ استخراج فایل
- فایل ZIP را در پوشه مناسب استخراج کنید
- فایل‌های فارسی‌سازی آماده است!

## 🛠️ ساختار مخزن GitHub

برنامه به صورت خودکار محصولات را با الگوی زیر تشناخت می‌دهد:

```
Repository:
├── AMOZISH.md           ← توضیحات متنی
├── AMOZISH.png          ← تصویر محصول
├── AMOZISH.zip          ← فایل دانلود (محتوا)
├── GAME1.md
├── GAME1.jpg
├── GAME1.zip
└── ...
```

**نام‌گذاری**:
- اسم فایل: `PRODUCTNAME.EXTENSION`
- هر فایل با اسم یکی = یک محصول
- پسوند: `.md` یا `.txt` (متن)، `.jpg`/`.png` (تصویر)، `.zip` (دانلود)

## 🐛 رفع مشکلات

### ❌ مشکل: برنامه باز نمی‌شود
**حل**: 
- Windows Defender/Antivirus غیرفعال کنید
- فایل را دوباره دانلود کنید
